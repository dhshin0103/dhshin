# 부기의 수학 모험

초등 3학년 1학기용 수학 플랫폼 게임 시제품입니다. 시작 전에 학년·학기 맵(1~6학년, 학기별 12개)을 고르고, 거북이 캐릭터 '부기'가 문제 문 5개를 열어 깃발까지 갑니다. 1-1부터 6-2까지 12개 맵마다 5문제(+비슷한 문제 5개)가 따로 있습니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구성

| 항목 | 내용 |
| --- | --- |
| 조작 | ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원 |
| 탐험 지도 | 남한 6개 권역 = 1~6학년 (1 제주, 2 전라, 3 경상·울릉도·독도, 4 충청, 5 강원, 6 수도권). 권역마다 1·2학기. 미탐험은 회색, 한 학기 완료는 빗금, 두 학기 완료는 색칠 |
| 타임어택 | 출발부터 깃발까지 걸린 시간이 기록. 오답 +5초, 보기는 1.2초 뒤 열림. 반 1등이 지역 깃발을 가져가고, 기록을 뺏겨도 탐험한 땅은 유지. 반 친구는 닉네임만 표시 (예시 데이터) |
| 문제 문 | 5개 (덧셈과 뺄셈, 평면도형, 나눗셈, 곱셈, 분수와 소수). 닿으면 문제가 나오고 맞히면 열림. 길이와 시간 문제는 코드에 남겨 둠 |
| 문제 은행 | 12개 맵 × 5문제 × (기본 + 비슷한 문제) = 120문항. 단원명은 교육과정 단원을 참고한 예시 |
| 취소·재시작 | 게임 중 상단 "처음부터"·"그만하기", 문제 창 "그만하기", 하트 소진 시 "맵으로". 실수 방지를 위해 두 번 눌러야 실행 |
| 오답 처리 | 풀이를 보여 주고 '비슷한 문제'로 다시 도전 |
| 헷갈이 | 위에서 밟으면 코인 +2, 옆에서 부딪히면 하트 -1 |
| 하트 | 3개. 모두 쓰면 마지막으로 연 문에서 다시 출발 |
| 엔딩 | 깃대 오르기 · 수학 기호 불꽃놀이 · 메달 (건너뛰기 가능) |
| 결과 | 한 번에 맞힌 수, 다시 도전 수, 코인, 다시 보면 좋은 단원 |
