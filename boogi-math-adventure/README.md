# 부기의 수학 모험

초등 수학 플랫폼 게임 시제품입니다. 학년마다 캐릭터 친구가 있고, 단원에서 별 3개를 모으면 그 학년 퍼즐 조각을 하나 얻습니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구조

```
학년 6개 (캐릭터)
 1학년 송이네 숫자 교실 · 2학년 루미네 구구단 가게 · 3학년 부기네 계산 수리점
 4학년 로키네 도형 퀴즈쇼 · 5학년 달이의 분수 탐정 사무소 · 6학년 토리의 비율 열기구
 └─ 단원 10개 (1학기 5 + 2학기 5) = 퍼즐 조각 10개 (5 × 2 직소 퍼즐, 완성하면 캐릭터 그림)
     └─ 단원 스테이지 = 문제 문 2개 (기본 + 응용), 틀리면 풀이 + 비슷한 문제
```

| 규칙 | 내용 |
| --- | --- |
| 별 3개 | ① 깃발까지 완주 ② 문제를 한 번에 모두 맞히기 ③ 하트 지키기(한 번도 다치지 않기). 단원별 최고 별 수를 저장 |
| 퍼즐 조각 | 단원에서 별 3개를 처음 받으면 그 단원 번호의 조각 1개. 지도 대신 학년 퍼즐 판에 끼워짐 |
| 학년 완성 | 10조각을 모두 모으면 엔딩 연출 + 다음 학년 열림 |
| 잠금 | 내 학년(예시 3학년)과 그 이전 학년은 열림, 다음 학년은 앞 학년 퍼즐 완성 시 열림 |
| 결과 화면 | 별 3개 체크리스트 + 조각 획득 여부 + **다음 단원 ▶** (마지막 단원이면 다음 학년으로), 다시 도전, 단원 목록 |

## 기타

- 조작: ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원
- 게임 중 "처음부터"·"그만하기" (두 번 눌러야 실행)
- 캐릭터는 스쿨플랫 캐릭터(송이·루미·부기·로키·달이·토리)를 참고해 단순하게 그린 시제품용 SVG입니다. `charSVG()`를 정식 그림 파일로 바꾸면 카드·퍼즐 그림에 그대로 반영됩니다.
- 진행 상황은 브라우저 `localStorage`에만 저장
