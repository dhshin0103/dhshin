# 부기의 수학 모험

초등 수학 플랫폼 게임 시제품입니다. 대한민국(남한) 지도 퍼즐에서 학년별 조각을 고르고, 조각 안의 도시(단원)를 모두 정복하면 그 퍼즐 조각이 맞춰집니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구조

```
남한 퍼즐 (6조각을 모두 맞추면 완성)
 └─ 퍼즐 조각 6개 = 학년
     1학년 제주도 · 2학년 전라도 · 3학년 경상도(울릉도·독도) · 4학년 충청도 · 5학년 강원도 · 6학년 경기도(서울·인천)
     └─ 도시 10개 = 그 학년 단원 10개 (1학기 5 + 2학기 5)
         └─ 도시 학습 스테이지 = 단원 문제 2개 (기본 + 응용), 틀리면 풀이 + 비슷한 문제
```

| 단계 | 화면 | 규칙 |
| --- | --- | --- |
| 퍼즐 지도 | 어린이용 대한민국 지도 스타일(파스텔 지역 색, 진한 테두리, 작은 섬, 바다 이름·물결·배·물고기) + 조각 목록 | 맞춘 조각 = 파스텔 컬러 3D(두께·그림자), 못 맞춘 조각 = 흑백, 잠긴 조각 = 흑백 + 자물쇠 |
| 지역 지도 | 그 지역만 확대한 지도 + 학기별 도시 목록. 도시마다 이름과 단원 표시 | 도시를 누르면 목록에서 강조. "정복하기"로 학습 시작 |
| 도시 학습 | 플랫폼 게임. 문제 문 2개를 열고 깃발까지 | 깃발 도착 = 도시 정복. 10곳 정복 = 퍼즐 조각 완성(엔딩 연출 + 조각이 끼워지는 애니메이션) |
| 잠금 | 내 학년(예시 3학년)과 그 이전 지역은 열림 | 다음 학년 지역은 앞 지역 10곳을 모두 정복해야 열림 |
| 타임어택 | 정복한 도시에서 열림 | 출발부터 깃발까지 시간으로 반 순위. 오답 +5초, 보기는 1.2초 뒤 열림. 반 친구는 닉네임만 (예시 데이터) |

## 기타

- 조작: ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원
- 게임 중 "처음부터"·"그만하기" (두 번 눌러야 실행)
- 문제 은행: 1-1 ~ 6-2 각 5문제 × (기본 + 비슷한 문제). 도시 하나는 그중 한 단원의 기본·응용 2문제를 사용
- 지도 경계는 실제 시·도 경계입니다. 통계청(KOSTAT) 2018 시·도 경계를 정리한 공개 자료 [southkorea-maps](https://github.com/southkorea/southkorea-maps)의 `skorea-provinces-2018-geo.json`을 `geo2js.py`로 단순화(약 4,300점, 54KB)해 `index.html`에 넣었습니다. 바다 꾸미기(물결·배·물고기·구름)는 직접 그린 단순 도형입니다.
- 학년 조각 = 시·도 묶음: 1 제주 / 2 전남·전북·광주 / 3 경북·경남·대구·울산·부산 / 4 충남·충북·대전·세종 / 5 강원 / 6 경기·서울·인천

```bash
python3 geo2js.py skorea-provinces-2018-geo.json prov.js   # PROV 데이터 다시 만들기
```
- 진행 상황은 브라우저 `localStorage`에만 저장
