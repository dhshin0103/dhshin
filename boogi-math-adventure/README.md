# 부기의 수학 모험

초등 수학 플랫폼 게임 시제품입니다. 동물 마을 **매스 랜드**의 숫자 시계탑에서 황금 나침반이 부서졌고, 수학 탐험가가 단원 섬마다 7명의 수호자 관문을 통과하며 나침반 조각을 되찾는 이야기입니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구조

```
매스 랜드 (숫자 시계탑의 황금 나침반이 부서진 이야기)
 └─ 학년·학기 + 단원 선택 = 단원 섬 지도 (시제품 콘텐츠: 3-1 분수와 소수, 5-1 다각형의 둘레와 넓이)
     └─ 관문 8개: 1 송이 개념 열기 · 2 루미 어휘/단위 · 3 로키 기초 연산(10초) · 4 부기 개념 적용
                  5 달이 서술·응용(단서 밑줄) · 6 토리 실생활 연계 · 7 샌디 오답 정리 · 최종 보물지도 단원평가
         └─ 관문을 별 3개로 통과 = 황금 나침반 퍼즐 조각 1개 (1~7 바깥 조각 + 보물지도 = 가운데 바늘)
             8조각 완성 → 숫자 시계탑이 다시 움직임 (엔딩 연출)
```

| 화면 | 내용 |
| --- | --- |
| 첫 화면 | 큰 섬 지도 + 옆 황금 나침반 퍼즐 현황. 지도의 관문마다 단계, 수호자, 배우는 내용, 별 표시 |
| 이야기 | 처음 들어오면 3장(시계탑 → 나침반이 부서짐 → 수호자를 만나 조각 되찾기). "이야기 보기"로 다시 보기 |
| 별 3개 | ① 깃발까지 완주 ② 문제를 한 번에 모두 맞히기 ③ 하트 지키기. 보물지도는 정답 수 기준 |
| 기타 | 관문 잠금(열쇠), 코인 상점(힌트·시간 멈추기·하트·보호막), 단원 배지, 결과 화면 "다음 관문 ▶" |

## 기타

- 조작: ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원
- 게임 중 "처음부터"·"그만하기" (두 번 눌러야 실행)
- 캐릭터는 스쿨플랫 캐릭터(송이·루미·부기·로키·달이·토리·샌디)를 참고해 단순하게 그린 시제품용 SVG입니다. `charSVG()`를 정식 그림 파일로 바꾸면 지도·퍼즐·이야기 그림에 그대로 반영됩니다.
- 진행 상황은 브라우저 `localStorage`에만 저장
