# 부기의 수학 모험

초등 3학년 1학기용 수학 플랫폼 게임 시제품입니다. 거북이 캐릭터 '부기'가 달리며 길을 막은 문제 문 10개를 열고 깃발까지 갑니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구성

| 항목 | 내용 |
| --- | --- |
| 조작 | ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원 |
| 문제 문 | 10개. 닿으면 문제가 나오고 맞히면 열림 (2022 개정 3-1 단원: 덧셈과 뺄셈, 평면도형, 나눗셈, 곱셈, 길이와 시간, 분수와 소수) |
| 오답 처리 | 풀이를 보여 주고 '비슷한 문제'로 다시 도전 |
| 헷갈이 | 위에서 밟으면 코인 +2, 옆에서 부딪히면 하트 -1 |
| 하트 | 3개. 모두 쓰면 마지막으로 연 문에서 다시 출발 |
| 엔딩 | 깃대 오르기 · 수학 기호 불꽃놀이 · 메달 (건너뛰기 가능) |
| 결과 | 한 번에 맞힌 수, 다시 도전 수, 코인, 다시 보면 좋은 단원 |
