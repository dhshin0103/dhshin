# 부기의 수학 모험

초등 수학 플랫폼 게임 시제품입니다. 동물 마을 **매스 랜드**의 숫자 시계탑에서 황금 나침반이 7조각으로 부서졌고, 수학 탐험가가 7개 구역의 친구들을 만나 미션을 해결하며 조각을 되찾는 이야기입니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구조

```
매스 랜드 지도 (가운데 숫자 시계탑 = 황금 나침반 7칸)
 └─ 구역 7개 (길로 이어짐, 앞 구역 퍼즐을 완성하면 다음 구역의 안개가 걷힘)
     1학년 송이네 숫자 교실 · 2학년 루미네 구구단 가게 · 3학년 부기네 계산 수리점
     4학년 로키네 도형 퀴즈쇼 · 5학년 달이의 분수 탐정 사무소 · 6학년 토리의 비율 열기구
     마지막 구역 샌디의 비밀기지 (학년별 복습 6 + 섞어 풀기 3 + 시계탑 최종 미션)
     └─ 단원 10개 = 구역 퍼즐 10조각 (5 × 2 직소, 완성하면 캐릭터 그림)
         └─ 단원 스테이지 = 문제 문 2개 → 별 3개면 퍼즐 조각 1개
 구역 퍼즐 완성 = 황금 나침반 조각 1개 → 7개 모두 모으면 시계탑이 다시 움직임
```

| 규칙 | 내용 |
| --- | --- |
| 이야기 | 처음 들어오면 3장짜리 이야기(시계탑 → 나침반이 부서짐 → 탐험가의 모험). 지도 제목 옆 "이야기 보기"로 다시 볼 수 있음 |
| 구역 친구 대사 | 구역에 들어가면 지키는 친구가 미션을 부탁하는 대사 |
| 별 3개 | ① 깃발까지 완주 ② 문제를 한 번에 모두 맞히기 ③ 하트 지키기(한 번도 다치지 않기) |
| 결과 화면 | 별 체크리스트 + 조각 획득 여부 + **다음 단원 ▶** (마지막 단원이면 다음 구역으로), 다시 도전, 단원 목록 |
| 잠금 | 내 학년(예시 3학년) 구역과 그 이전은 열림, 나머지는 안개 + 자물쇠 |

## 기타

- 조작: ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원
- 게임 중 "처음부터"·"그만하기" (두 번 눌러야 실행)
- 캐릭터는 스쿨플랫 캐릭터(송이·루미·부기·로키·달이·토리·샌디)를 참고해 단순하게 그린 시제품용 SVG입니다. `charSVG()`를 정식 그림 파일로 바꾸면 지도·퍼즐·이야기 그림에 그대로 반영됩니다.
- 진행 상황은 브라우저 `localStorage`에만 저장
