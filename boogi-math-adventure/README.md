# 부기의 수학 모험

초등 수학 플랫폼 게임 시제품입니다. 동물 마을 **매스 랜드**의 숫자 시계탑에서 황금 나침반이 부서졌고, 수학 탐험가가 단원 섬마다 7명의 수호자 관문을 통과하며 나침반 조각을 되찾는 이야기입니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 원본 아티팩트: https://claude.ai/artifact/VybUZZkGNZ9MaHfYeXomFy

## 실행

```bash
cd boogi-math-adventure && python3 -m http.server 8000
```

## 구조

```
매스 랜드 · 숫자 시계탑 (층 = 학년, 방 = 단원)
 └─ 단원의 방 지도 (전체 화면, 시계탑 내부 계단 → 끝에 '숫자 시계탑의 심장')
     └─ 5단계 (뒤로 갈수록 어려워짐, 시간 제한 없음)
         1 송이 개념 탐구(하) → 2 부기 유형 연습(중) → 3 달이 생각 쑥쑥·문장제(상)
         → 4 로키 단원 총괄 6문항(평가) → 5 샌디 비밀 기지: 틀린 문제 쌍둥이 + 도전 문제(마스터)
         └─ 단계를 별 3개로 통과 = 황금 나침반 조각 1개 (5조각)
 5/5 → 마지막 정답 0.5초 뒤 자동 축하 연출 → 마스터 배지 + 코인 100
```

| 화면 | 내용 |
| --- | --- |
| 지도 | 전체 화면. 왼쪽 위 '[3학년] 시계탑 3층 : 분수와 소수의 방', 오른쪽 위 작은 나침반(테두리 게이지 n/5, 누르면 수집 현황), 관문마다 단계·장소·미션·난이도·별. 잠긴 방은 흐림 + 자물쇠, 현재 관문에 통통 튀는 핀 |
| 풀스크린 이야기 | 관문을 누르면 그 친구의 공간으로 화면 전환. 큰 캐릭터 + 아래 대화창, 터치해서 계속 → 마지막에 아이템 선택 후 줌아웃하며 게임 시작 |
| 로키의 돌발 퀴즈 | 지도 왼쪽 아래. 30초 동안 단순 계산(구구단·덧셈), 정답마다 코인 2개. 타임어택은 여기서만 |
| 완성 연출 | 나침반이 오른쪽 위에서 가운데로 확대 → 마지막 조각이 끼워지며 섬광 → 바늘이 돌다 12시에 멈춤 → 시계탑 톱니·종 → 폭죽·7명 "축하해! 3층 복원 완료!" → 3초 뒤 마스터 배지와 '다음 층으로'. 5번째 조각을 얻는 순간 자동 재생(버튼 없음), 배지 화면의 '다시 보기'로 다시 볼 수 있음 |

## 기타

- 조작: ←/→ 이동, 스페이스 점프, 문제는 1~4 숫자 키. 화면 아래 터치 버튼 지원
- 게임 중 "처음부터"·"그만하기" (두 번 눌러야 실행)
- 캐릭터는 스쿨플랫 캐릭터(송이·루미·부기·로키·달이·토리·샌디)를 참고해 단순하게 그린 시제품용 SVG입니다. `charSVG()`를 정식 그림 파일로 바꾸면 지도·퍼즐·이야기 그림에 그대로 반영됩니다.
- 진행 상황은 브라우저 `localStorage`에만 저장
