# 수학 퀘스트 프로토타입 (1차 실험실 버전)

학생 자기주도학습용 게이미피케이션 테스트 페이지입니다. 빌드나 서버 없이 `index.html` 하나로 동작합니다.

## 실행

```bash
cd math-quest && python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. 파일을 직접 열어도 동작합니다.

## 1차 범위

| 영역 | 내용 |
| --- | --- |
| 홈 | "오늘의 모험 시작" 한 버튼. 틀린 문제가 3개 이상이면 다시 풀기, 아니면 숙련도가 가장 낮은 단원을 자동 추천 |
| 메뉴 | 홈 · 내 기록 · 상점 (3개). 숙제·우리 반 제외 |
| 모드 | 차근차근 풀기(성장의 숲) · 시간 도전(불꽃의 협곡) · 틀린 문제 다시 풀기(지혜의 탑) |
| 단원 | 학년·학기는 계정에서 자동 설정, 직접 고를 때도 대단원까지만 (예시: 3학년 2학기 5개 단원) |
| 코인 기준 | 정답 1개 = 10코인 · 3연속 정답마다 +5 · 하루 최대 300코인. 홈과 문제 화면에 상시 표시 |
| 틀린 문제 | 게임에서 틀린 문제가 자동으로 모이고, 맞히면 목록에서 빠짐 |
| 찍기 방지 | 보기는 1.5초 뒤 열림 · 너무 빠른 정답은 코인 0 · 빠른 답 3연속 중 2개 이상 오답이면 4초 휴식 · 보기 순서 섞기 · 하루 코인 상한 |
| 내 기록 | 이번 주 푼 문제(지난주 대비) · 정답률 · 연속 학습일 · 극복한 틀린 문제 · 요일별 그래프 · 단원별 숙련도 · 학습 성향 · 배지 |
| 상점 | 캐릭터 꾸미기 6종 + 코인 획득·사용 흐름 안내 |
| 교사 | "수업 중 사용 제한" 설정만 (출제·채점 없음) |

랭킹(반별·학교별)은 개인정보 검토 후 2차에서 다룹니다.

## 테스트 도구

화면 맨 아래에 있으며 실제 학생 화면에는 노출하지 않습니다.

- **교사: 수업 중 사용 제한** — 학생 화면 잠금 확인
- **하루 지나기** — 연속 학습일, 오늘 목표, 코인 상한 초기화 확인
- **처음 상태로** — 예시 데이터로 초기화 (두 번 눌러야 실행)

## 참고

- 학생 이름, 점수, 기록은 모두 예시 데이터입니다.
- 진행 상황은 브라우저 `localStorage`(`mq-proto-v2`)에만 저장됩니다.
- 찍기 방지 시간 기준(1.5초, 2.5초)은 가정치이며, 실험실 데이터로 학년별 기준을 정해야 합니다.
